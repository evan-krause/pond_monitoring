## 3. Building depth-by-date profile heatmaps

**User:** Depth-by-date heatmaps for each parameter (classic limnology profile plot showing stratification over the season), using `geom_tile()` or `geom_raster()` with interpolation.

The assistant:

- Checked sampling density per station: LP1 has 5 dates (2025 only, May–Sep); LP2 and LP3 each have 8 dates split across two seasons — 5 in 2025 (May–Sep) and 3 in 2026 (Jun–Aug) — with roughly a 9-month gap between seasons.
- Chose the `interp` package (an actively maintained, permissively licensed fork of `akima`) to interpolate irregular depth/date samples onto a regular grid suitable for `geom_raster()`.
- Wrote `make_profile_grid()` to interpolate a single station/year group, and `plot_profile_heatmap()` to render the raster with actual sample points overlaid as white dots, reversed depth axis, and viridis fill.
- Deliberately faceted by year rather than interpolating across the multi-month sampling gap between the 2025 and 2026 seasons, to avoid implying data that doesn't exist.
- Verified the approach on `temp_c`, `do`, and `chla`, fixing x-axis date formatting along the way.

## 4. Splitting the heatmaps by site

**User:** separate heatmaps by site

The assistant refactored `plot_profile_heatmap()` to take a `station_id` argument and produce one plot per site (faceted only by year), rather than combining all three stations into one panel. This let each site's own depth range display properly (LP1 tops out around 4 m; LP2/LP3 reach \~7 m). The assistant then generalized the code to loop over all 10 parameters x 3 stations (30 combinations), fixed a bug where sparse groups (e.g. `pH` in some station/year combinations) caused `group_modify()` to error, and spot- checked a couple of the resulting plots (`pH_lp3`, `chla_lp2`).

Caveats noted to the user: - Sampling is sparse (5–8 dates per site per season), so the linear interpolation is a smooth guess between visits, not a measured field. - Empty facets (e.g. `pH_lp3` in 2026) reflect genuinely missing data for that parameter/year, not a plotting error.
